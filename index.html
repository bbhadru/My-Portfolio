E-Bank26 – Core Banking Management System Full-Stack Project

E-Bank26 is a full-stack web application designed to simplify banking operations for cooperative banks, credit societies, and microfinance institutions. It supports customer and account management, deposit and transaction processing, loan EMI calculations using reducing-balance and flat-rate methods, fixed-deposit maturity processing, and financial reporting. The application follows a layered MVC architecture and uses Java 21, Spring Boot, Spring Security, Spring Data JPA, Hibernate, Thymeleaf, Bootstrap, and MySQL.

Development Process

  • Identified banking requirements and designed the layered MVC architecture.
  • Developed backend services and business logic using Java and Spring Boot.
  • Integrated MySQL using Spring Data JPA and Hibernate.
  • Built the user interface using Thymeleaf, HTML, CSS, and Bootstrap.
  • Implemented authentication using Spring Security and JWT.
  • Added double-entry accounting, general ledger posting, Trial Balance, and Profit & Loss reports.
  • Documented REST APIs with Swagger/OpenAPI and tested endpoints using Postman.
  • Added Excel and PDF report exports and configured the environment using Docker.
